# 商装工坊网页版 V2

与微信小程序功能一致的商家 AI 创作网站，包含动态品牌首页、会员登录和完整创作工作台。

## 已包含

- 动态首页：文字轮换、创作轨道、跟随光影、快速生成演示
- 图片设计：营销海报、朋友圈海报、门店物料、自主设计
- 短视频：商家素材成片、声音克隆与对口型视频入口
- 行业案例：图片及短视频案例库
- 素材空间：图片、视频、字体和品牌元素
- 会员资产：积分、素材和克隆声音概览

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可。本项目与原版项目相互独立，正式环境将通过宝塔面板部署和维护。
