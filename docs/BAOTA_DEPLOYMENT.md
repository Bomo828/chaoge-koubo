# 宝塔面板部署手册

本项目采用 **宝塔面板 + Node.js 项目 + Nginx 反向代理** 的部署方式。以下步骤均可在宝塔网页界面完成。

## 1. 服务器准备

在宝塔“软件商店”安装：

- Nginx
- Node.js 版本管理器
- Node.js 22

建议项目目录：

```text
/www/wwwroot/merchant-studio-web-v2
```

## 2. 上传与构建

1. 在宝塔“文件”中上传项目压缩包并解压到项目目录。
2. 不要上传本机的 `node_modules`、`.next` 和开发日志。
3. 在项目目录安装依赖并执行生产构建：

```text
pnpm install --frozen-lockfile
pnpm run build
```

4. 在服务器创建 `.env.production`，正式密钥只保存在服务器，不写入前端代码。

## 3. 创建 Node 项目

在宝塔“网站 → Node 项目”中新建项目：

- 项目目录：`/www/wwwroot/merchant-studio-web-v2`
- Node 版本：22
- 启动命令：`pnpm run start:baota`
- 应用端口：`3001`
- 运行用户：使用宝塔默认网站用户
- 开机自启：开启

启动后先在宝塔内检查：

```text
http://127.0.0.1:3001/api/health
```

## 4. 域名与 HTTPS

1. 在宝塔“网站”创建或选择已备案域名。
2. 添加反向代理，目标地址填写 `http://127.0.0.1:3001`。
3. 在 SSL 页面申请或上传证书，并开启强制 HTTPS。
4. 公网检查首页、登录、工作台、管理员后台和 `/api/health`。

## 5. 数据与备份

以下目录不能在更新代码时覆盖或删除：

```text
.data/
```

其中包含 SQLite 数据库、会员资产、上传文件和模板素材。请在宝塔“计划任务”中为 `.data/` 配置每日备份，并至少保留 7 个历史版本。

发布新版本时只替换代码和构建产物，不覆盖 `.data/` 与 `.env.production`。

## 6. 上线前检查

- 修改默认管理员密码并关闭演示账号。
- 将短信验证、微信支付、AI 密钥、回调地址改为正式配置。
- 确认积分扣减、失败退款和资产保存正常。
- 确认用户端与管理员端均不存在“店铺装修”入口。
- 确认 Nginx 上传大小和请求超时能支持视频文件。
- 确认数据库和会员素材可以从备份恢复。
