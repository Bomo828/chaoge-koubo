# 第三方素材说明

本文件用于公开前审计，不构成任何第三方素材的授权证明。

## 当前原则

1. 代码开源与素材授权分开处理。
2. “可商用”只表示可在成片或商业项目中使用，不代表可以把原始文件随源码公开下载。
3. 只有附带明确开源许可证或获得权利人书面再分发授权的素材才进入公开仓库。
4. 用户上传或自行购买的素材由部署者自行保存，不进入 Git。

## 已知检查项

- 仓库中部分字体附带 SIL Open Font License 等许可证文件，可在遵守对应许可证的前提下保留。
- 网感模板使用的部分字体需要逐一确认来源和再分发权；无法确认时应替换为开源字体。
- 商业 BGM、口播音效和剪映素材包即使声明可商用，也应在取得“原文件可再分发”证明前从公开仓库排除。
- 原片、测试视频、声音样本和用户生成成片不属于开源示例资产。

## 公开仓库替代方案

- 提供空目录、占位文件和命名规范。
- 提供资源校验脚本或配置字段，由部署者自行放入素材。
- 使用 CC0、OFL、MIT 或其他明确允许再分发的替代资源。
- 在模板加载失败时给出清楚提示，不静默回退到未经授权的素材。

公开前请为每项素材补齐来源、作者、许可证、再分发结论和处理结果。
