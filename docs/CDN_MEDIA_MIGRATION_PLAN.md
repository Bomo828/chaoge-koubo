# CDN 媒体全量迁移实施计划

本文用于在正式 CDN 媒体域名完成备案、解析与 HTTPS 后，将项目图片、模板预览、视频封面和成片逐步迁移到 COS/CDN。当前已完成公开图片、模板封面和首页预览视频的 COS 上传与 CDN 验证；生产切流仍以 HTTPS 证书生效为前提。

## 1. 目标与边界

- 公开首页保持轻量，静态图片与背景视频由 CDN 就近分发。
- 工作台先显示页面框架，用户进入功能后才加载模板、会员资产和业务数据。
- 视频先展示首帧封面，播放时使用 Range 分段读取，不在页面打开时下载完整视频。
- 私有会员资产继续由服务端鉴权；不得为了 CDN 命中率改成永久公开链接。
- 迁移必须可以按资源类别单独回退，不能一次性替换全部线上地址。

## 2. 上线前置条件

1. 准备独立媒体域名，例如 `media.example.com`，完成备案、DNS 解析和 HTTPS 证书。
2. CDN 回源到与主站、渲染节点同地域的 COS，不经主站服务器中转公开静态资源。
3. 明确两类资源：
   - 公开资源：品牌图片、首页视频、模板封面、模板预览。
   - 私有资源：用户上传素材、会员成片、会员封面、支付或账户相关附件。
4. 公开资源使用版本化路径或内容哈希；私有资源使用短时签名 URL 或 CDN 鉴权。
5. 所有真实 Bucket、域名、密钥、商户号和服务器地址只写入服务器环境变量，不进入 Git。

## 3. 建议的资源目录

```text
public/
  brand/v1/                 品牌 Logo、标题图和首页首帧
  landing/v1/               首页背景视频与展示媒体
  templates/<version>/      模板封面、预览视频和模板公开素材
  industries/<version>/     行业示例与图片创作示例

private/
  members/<member-id>/      会员图片、视频、音频与封面
  jobs/<job-id>/            任务输入、中间文件与结果
  temp/<date>/              可按生命周期清理的临时文件
```

目录中不得出现手机号、用户名、身份证号或其他直接身份信息。会员与任务目录使用不可预测标识。

## 4. 分阶段迁移

当前实施状态：

- 阶段 A：已完成 COS 上传、最小路径授权、CDN 裸地址和长期缓存验证。
- 阶段 B：已完成首页背景视频上传，并验证 `Content-Type`、`Accept-Ranges` 与裸地址访问。
- 阶段 C：已完成。会员资产继续通过 `/api/member/assets/:id` 校验登录和会员归属；COS 资产在鉴权后返回短时签名地址，本地兼容资产继续由受保护接口提供 Range 响应。播放、封面与下载采用不同有效期，下载地址禁止公共缓存。
- 阶段 D：已完成。独立渲染节点把 MP4 与封面直接写入 COS，任务状态只回传对象键和校验信息；主站向渲染节点复核任务成功及对象键后登记会员资产元数据，不再搬运云端成片。

### 阶段 A：公开静态图片

迁移 Logo、首页标题图、行业图片、模板封面。代码通过统一的公开媒体基址生成 URL；基址为空时继续使用站内 `/media`、`/template-covers` 和 `/industry-image-lab`。

验收后再进入下一阶段。此阶段最容易回滚，也最适合验证缓存、跨域和 HTTPS。

### 阶段 B：首页与模板预览视频

迁移首页背景视频和模板预览。每条视频必须同时准备：

- MP4/H.264 主文件；
- JPG 或 WebP 首帧封面；
- 正确的 `Content-Type`；
- `Accept-Ranges: bytes`；
- 对 Range 请求返回 `206 Partial Content` 和正确 `Content-Range`。

页面继续使用 `preload="none"` 或 `preload="metadata"`，不得因接入 CDN 改回首屏完整预载。

### 阶段 C：会员成片与视频封面

会员资产接口保留登录鉴权。鉴权成功后可返回短时签名 CDN URL，或由受保护下载接口继续提供 Range 响应。播放 URL 与下载 URL 分离：

- 播放 URL：短时有效、支持 Range、默认内联展示。
- 下载 URL：更短有效期、强制附件下载、禁止公共缓存。
- 封面 URL：允许较长私有缓存，但不能跨会员复用鉴权结果。

### 阶段 D：渲染产物直写 COS

渲染服务器完成任务后直接把 MP4、封面和清单写入 COS，主站只登记资产元数据，不再搬运大文件。任务完成通知只包含对象键、大小、类型和校验信息，不携带长期公开地址。

## 5. 缓存策略

| 资源 | 建议浏览器缓存 | 建议 CDN 缓存 | 失效方式 |
| --- | --- | --- | --- |
| 内容哈希品牌图片 | 1 年，`immutable` | 1 年 | 文件名换哈希 |
| 版本化模板封面/预览 | 7–30 天 | 1 年 | 模板版本目录升级 |
| 首页背景视频 | 7 天 | 30–365 天 | 文件名或版本目录升级 |
| 会员视频封面 | 私有 1 天 | 按鉴权策略 | 签名过期或资产版本变化 |
| 会员成片播放 | 私有短时 | 私有 CDN 短时 | 签名过期 |
| 会员成片下载 | `private, no-store` | 不缓存或极短时 | 单次签名过期 |

不要用查询参数长期承担版本控制；公开资源优先使用版本目录或内容哈希文件名。

## 6. CORS 与响应头

- 只允许正式站点、预发布站点和明确的本地开发 Origin。
- 允许 `GET`、`HEAD`，浏览器直传场景再单独开放必要方法。
- 请求头至少允许 `Range`、`Content-Type` 和签名所需请求头。
- 暴露 `Accept-Ranges`、`Content-Range`、`Content-Length`、`ETag`、`Last-Modified`。
- 视频、图片和字体返回正确 `Content-Type` 与 `X-Content-Type-Options: nosniff`。
- 禁止 `Access-Control-Allow-Origin: *` 与凭证模式同时使用。

## 7. 上线验收

### 图片与封面

- 首页、模板库、市场动态和会员资产均能显示真实封面。
- 首次请求为 CDN MISS，重复请求可看到 HIT 或缓存年龄增长。
- 替换版本后新 URL 立即生效，旧缓存不污染新资源。
- 移动端没有因图片迟到产生明显布局跳动。

### 视频播放

- 初始页面只请求封面或少量 metadata，不读取完整 MP4。
- 点击播放后出现 Range 请求；响应为 `206`，`Content-Range` 与文件大小一致。
- 可拖动到中后段继续播放，刷新后仍能正常起播。
- Chrome、Safari、微信内置浏览器和移动网络至少各完成一次验证。

### 下载

- 下载文件扩展名、MIME、文件大小和内容一致。
- 下载 URL 不指向内网地址，不经过仅本机可访问的域名。
- 过期签名返回明确错误，重新获取链接后可恢复。

### 安全与隔离

- 未登录、跨会员和已删除资产均无法读取。
- 日志不记录完整签名 URL、API Key、Cookie 或微信支付密钥。
- CDN 回源权限只覆盖所需路径，私有目录不允许匿名列举。

## 8. 切流与回滚

1. 先让内部账号使用 CDN 基址，观察 24 小时错误率、回源率和带宽。
2. 再按公开图片、模板预览、会员封面、会员成片的顺序逐项放量。
3. 每一步都保留原站内路径或服务端资产接口作为回退。
4. 出现 CORS、Range、签名、下载或缓存污染问题时，只回退对应资源类别。
5. 完成全量迁移并稳定运行后，再清理旧公开副本和临时兼容变量。

## 9. 实施完成标准

- 首页和工作台的首屏不依赖完整视频下载。
- 公开媒体主要由 CDN 命中，主站带宽不再承担热门预览。
- 会员资产仍保持登录鉴权、跨用户隔离与可审计下载。
- 视频播放支持分段、拖动和恢复，下载在桌面与移动端均成功。
- 迁移与回滚不需要重新构建全部应用，只需切换受控媒体基址或资源版本。
