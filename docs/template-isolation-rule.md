# 网感模板隔离规则

从模板契约版本 `package_contract_version: 3` 开始，每个模板必须是完整、独立、可审计的资源包。该规则由服务端加载器强制执行，不能依靠人工约定绕过。

## 强制要求

1. `package_mode` 必须为 `isolated`。
2. `fallback_policy` 必须为 `forbid-cross-template`。
3. `renderer_key` 必须以当前模板 ID 开头；例如 `high-red-editorial-v1`。
4. 背景音乐只能读取 `music/<template-id>/` 下的文件。
5. 开场、强调、转场和收尾音效只能读取 `sfx/<template-id>/` 下的文件。
6. 模板必须独立声明标题、字幕、关键词、转场、镜头、结尾、音乐、音效和质量门槛。
7. 口播字幕必须同时通过：语音时间覆盖率、字数覆盖率、逐字内容相似度。任何一项不达标都停止生成，禁止用“字数相近”冒充内容一致。
8. 渲染器不得截断字幕。长句只能均衡换行或拆成有时间轴的短句，不能删除剩余字符。
9. 新模板先完成本地逐帧验收，再修改状态并同步云端。
10. 每个新模板必须包含 `release_checklist_file`，并在交付时向用户发送该模板的验收清单；清单必须列出背景音乐、音效、可见转场及其验收时间点。

## 高级红当前门槛

- 逐帧分析：每一个解码帧。
- 字幕文字相似度：不低于 0.94。
- 字幕字数覆盖率：不低于 0.95。
- 人声时间覆盖率：不低于 0.94。
- 跨模板回退：禁止。
- 音乐和音效：只允许使用 `high-red` 专属目录。
