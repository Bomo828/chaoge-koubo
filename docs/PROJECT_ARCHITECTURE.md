# 爆点实验室项目架构

## 范围

本仓库是爆点实验室的完整生产项目，不只是网感模板。它包含用户工作台、管理后台、会员注册与资产、积分和微信支付、图片创作、短视频工具、市场动态、AI 助手，以及独立的视频渲染服务。

## 服务分工

### 主站

- Next.js 用户工作台与管理后台
- 会员、邀请码、积分账户、充值和消费记录
- 微信支付下单、回调验证和积分入账
- 会员资产、模板管理、AI 服务配置和市场动态
- 对浏览器隐藏第三方密钥，并向独立视频服务转发受控请求

### 独立渲染节点

- 视频上传、探测、语音识别与时间轴处理
- AI 超级剪辑、对口型衔接、一键网感和封面生成
- 模板 9–12 的 Remotion/FFmpeg 渲染
- 与腾讯云 COS、MPS、ASR 和第三方 AI 服务协作

### 数据与文件

- 业务数据：主站运行目录中的持久化 SQLite 数据库
- 视频和图片资产：腾讯云 COS 与会员资产记录
- 模板和只读素材：跟随独立渲染服务版本发布
- 密钥、证书和环境变量：只保存在服务器安全配置中，不进入 GitHub

生产部署的通用规格、网络、安全组、密钥分层、验收和扩容步骤见 [云服务器架构实施计划](CLOUD_DEPLOYMENT_PLAN.md)。准备公开源码时另请执行 [开源发布指南](OPEN_SOURCE_GUIDE.md) 和根目录 [安全策略](../SECURITY.md)。

## 发布流程

`main` 分支是唯一正式发布分支。提交后由 `.github/workflows/deploy-production.yml` 执行类型检查、代码检查和生产构建，再原子发布主站；视频服务目录发生变化时，同一工作流会增量发布独立渲染节点。

## 当前正式网感模板

仅保留模板 9–12：红白双语、黄白大字双语、青白高亮双语和黑黄聚焦双语。每套模板必须保持资源隔离，并遵循 `docs/template-isolation-rule.md`。

## 维护原则

1. 不在仓库中保存 `.env`、支付私钥、平台密钥和数据库运行文件。
2. 不保留与当前 Next.js + 腾讯云架构无关的演示脚手架。
3. 私有生产实施记录不进入公开仓库；公开文档只保留可复用、已脱敏的实施计划。
4. 生产变更必须通过 GitHub Actions 验证和发布，避免手工覆盖线上目录。
5. 会员、支付和视频渲染职责分离；扩容渲染节点不影响支付与会员数据。
