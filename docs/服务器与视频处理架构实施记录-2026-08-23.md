更新时间：2026-08-23

## 当前结论

新网感渲染节点已完成 Ubuntu 24.04 原生环境部署、四模板全链路测试，以及 AI/ASR 服务端凭据迁移。现有主服务器继续承担网站、会员、积分、充值、支付、管理后台和 API 调度；新服务器只承担模板 9–12 的 Remotion 与 FFmpeg 渲染。

## 支付模块位置

微信支付、充值订单、支付回调、积分入账、退款与账务记录继续部署在主服务器，不进入渲染服务器。视频任务仅在积分预扣成功后入队；任务失败由主服务器执行幂等退款。渲染节点不保存微信支付商户证书或支付密钥。

## 推荐切换顺序

1. 新节点安全组仅允许 `118.89.53.164/32` 访问 TCP 80。
2. 迁移 AI/ASR 服务端凭据并验证健康状态。
3. 创建受限 GitHub 发布账号并配置新节点发布目标。
4. 主站 `/video-worker` 服务端转发上游切到 `http://129.204.151.78/video-worker`；旧 Nginx 不变。
5. 用一条真实口播分别测试模板 9–12，确认字幕、关键词、音效、BGM、转场和下载。
6. 灰度观察后再停用主服务器旧视频进程。
7. 下一阶段接入 COS 直传与结果回写，减少视频在两台服务器之间重复传输。
