# 模板 11：青白高亮双语

- 参考片：`/Users/chaoge/Downloads/817.mp4`
- 画布：1080 × 1920，30fps，约 23.63 秒。
- 标题：左上常驻双行。第一行青色粗体、第二行白色常规体；黑色窄描边和明显右下阴影。
- 字幕：画面约 64.7% 高度居中，白色无衬线正文、青色粗体放大关键词，小号白色无衬线英文翻译置于下方。
- 动画：正文按字符渐显，关键词保持语义高亮；不做整组弹跳。
- 镜头：采用克制的语义景别切换，在 1.00–1.10 之间使用全景、轻近景和重点近景；不做连续软推近、横移、闪白或固定节奏循环。
- 声音：保留清晰人声；不铺循环背景音乐；仅在开场、少数关键词和结尾使用轻音效。
- 禁止：栏目编号、步骤标签、装饰卡片、无关小字、跨模板素材回退。
