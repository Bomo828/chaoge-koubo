# 网感模板独立化规范

## 目标

每套网感模板作为一个可独立设计、测试、定版和发布的模板包。模板之间不得共享或随机借用字体、字幕样式、标题样式、背景音乐、音效、转场和封面配置，避免修改一套模板时影响其他模板。

## 独立模板包

每个模板目录至少包含：

```text
template-X/
├── template.json
├── acceptance-checklist.md
├── materials.json                 # 有独立素材清单时使用
├── transition-library.json        # 有独立转场池时使用
└── reference-layout-spec.md       # 有参考片对齐要求时使用
```

模板专属素材必须进入自己的命名空间：

```text
public/fonts/template-X/
public/music/template-X/
public/sfx/template-X/
public/covers/template-X/
```

## 必须独立的内容

1. 模板名称、版本、状态和独立渲染器标识。
2. 标题字体、字号、排版、描边、阴影、位置和动画。
3. 正文字幕、关键词、双语字幕和入退场规则。
4. 背景音乐曲库、情绪匹配、音量、淡入淡出和循环策略。
5. 音效素材池、内容节点路由、音量和触发密度。
6. 转场素材池、触发条件、强度和最短间隔。
7. 封面样式、镜头策略、测试视频和验收报告。
8. 模板自己的素材授权、来源和校验信息。

## 可以共享的底层能力

以下能力可以由公共引擎复用，但不得替模板做风格决策：

- 视频解码、转码、合成和导出。
- 字幕时间轴解析与基础排版函数。
- 音轨混合、响度检测和自动压低。
- 逐帧坏帧检测、文本覆盖率和清晰度检测。
- 腾讯云 MPS、对象存储和任务队列连接。

## 隔离规则

- `package_mode` 必须为 `isolated`。
- `fallback_policy` 必须为 `forbid-cross-template`。
- `renderer_key` 必须全局唯一。
- 字体、音乐、音效、封面路径必须含模板自己的命名空间。
- 当前模板素材缺失时必须报错，不允许回退到其他模板素材。
- 修改已定版模板时必须增加版本号，保留上一版样片和对比报告。

## 定版与发布

每个模板单独完成以下流程：

1. 至少生成长、短两条本地样片。
2. 与固定参考片生成自动对比报告。
3. 检查标题、字幕、音效、背景音乐、转场和封面。
4. 逐帧验证坏帧为 0，确认音轨和字幕覆盖率。
5. 用户确认后标记为 `approved-local`。
6. GitHub 和腾讯云按模板包独立发布，未修改的模板不重新覆盖。
